# Portable room-key export interop

`portable-room-keys.ocaml.megolm` was generated by the OCaml executable
`generate_portable_export.exe` using passphrase
`ocaml-rust-portable-export` and PBKDF2 rounds `10000`. The expected decrypted
JSON is in `test/fixtures/portable-room-keys.expected.json`.

The Rust verifier uses the pinned SDK checkout at SHA
`523b5af53a8fd9fae9e2bc981bfb01ac86fd2890` and calls its public
`decrypt_room_key_export`, then compares every serialized field (including
`shared_history` and the forwarding chain):

```sh
dune exec test/interop/generate_portable_export.exe \
  | cmp - test/fixtures/portable-room-keys.ocaml.megolm
dune exec test/interop/generate_portable_export.exe -- --plaintext \
  | cmp - test/fixtures/portable-room-keys.expected.json
cargo run --offline --locked \
  --target-dir /tmp/ocaml-matrix-rust-export-target \
  --manifest-path test/interop/rust-export-verifier/Cargo.toml -- .
```

The pinned Rust checkout declares Rust 1.95. With the repository's currently
installed Rust 1.93.1 toolchain, the same verifier has been run successfully by
adding `--ignore-rust-version`; this is a temporary toolchain override, not a
weaker cryptographic check. `Cargo.lock` is committed so `--offline --locked`
uses the dependency set already fetched for the verifier.

To deliberately regenerate the fixtures, redirect the two generator forms to
their respective files and then rerun both comparisons and the Rust verifier.
