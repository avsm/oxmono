# Portable room-key export interop

`portable-room-keys.ocaml.megolm` is generated by `generate_portable_export.exe`
with passphrase `ocaml-rust-portable-export` and PBKDF2 rounds `10000`.
`test/fixtures/portable-room-keys.expected.json` is its expected plaintext.
The canonical shared-history field is `shared_history`; codec regressions also
cover `m.shared_history` and `org.matrix.msc3061.shared_history` on input.

The verifier calls the Rust SDK's public `decrypt_room_key_export` and compares
every serialized field, including the shared-history flag and forwarding chain.
The lockfile targets SDK `b3c07ea6ba6e8e46e30811c0500b04505c4be9f9`, which
requires Rust 1.96. Do not use `--ignore-rust-version`: Rust 1.93 cannot compile
its `cfg_select!` usage. The 2026-10-11 check passed with Docker
`rust:1.96` (image digest
`sha256:1f0dbad1df66647807e6952d1db85d0b2bda7606cb2139d82517e4f009967376`),
read-only SDK/Matrix source mounts, and `cargo run --offline --locked`.

From the OxMono root:

```sh
opam exec --switch=5.2.0+ox -- dune exec --profile release-check \
  bleeding/matrix/test/interop/generate_portable_export.exe \
  | cmp - bleeding/matrix/test/fixtures/portable-room-keys.ocaml.megolm
opam exec --switch=5.2.0+ox -- dune exec --profile release-check \
  bleeding/matrix/test/interop/generate_portable_export.exe -- --plaintext \
  | cmp - bleeding/matrix/test/fixtures/portable-room-keys.expected.json
bash bleeding/matrix/test/interop/run-rust-export.sh \
  ~/src/git/knot/matrix-rust-sdk --offline
```

`run-rust-export.sh` prints the selected SDK revision, creates a temporary
manifest pointing at that checkout, and uses the committed lockfile. It does
not modify either checkout. Omit `--offline` to fetch missing dependencies.
`MATRIX_RUST_EXPORT_TARGET` overrides its cached build directory in `/tmp`.
A different SDK revision may require a deliberate lockfile refresh.

To regenerate the fixtures, redirect the generator forms to their respective
files, rerun both comparisons, and run the independent Rust verifier.
