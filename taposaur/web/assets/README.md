# KaTeX

`katex.min.js` is the unmodified KaTeX 0.19.1 browser distribution from
https://cdn.jsdelivr.net/npm/katex@0.19.1/dist/katex.min.js.
The MIT licence is in `KATEX-LICENSE`.

The TEI reader uses MathML output, with native browser math fonts. It does
not load remote scripts, styles or fonts. Trust is disabled and expansion
and size budgets are set by the reader. Update the pinned version and test
both normal formulae and rejected commands when replacing this asset.
