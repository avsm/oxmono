# Protocol references

MQTT's wire protocols are OASIS standards. The local copies retain their
original notices. [sources.json](sources.json) records retrieval URLs,
SHA-256 digests and the retrieval date.

- [MQTT 3.1.1 plus Errata 01](mqtt-v3.1.1-errata01.html), 10 December 2015.
- [MQTT 5.0 OASIS Standard](mqtt-v5.0-os.html), 7 March 2019.
- [RFC 3629](rfc3629.txt), UTF-8 validation.
- [RFC 8446](rfc8446.txt), TLS 1.3. TLS is supplied by the vendored TLS stack.
- [RFC 9431](rfc9431.txt), ACE-MQTT authorization profile. Retained as a
  reference. ACE token and proof-of-possession flows are not implemented.
